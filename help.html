Help & Documentation

What is HuGGeMs?

HuGGeMs (Human Gut Microbial Gene Markers) is a comprehensive database of microbial gene markers derived from human gut metagenomes. It provides species-level genomic classifications, core gene clusters, and species-specific marker genes for metagenomic profiling and functional analysis.

How to Search

You can search by:

• Species name — full or partial name (e.g., Escherichia coli)

• Gene name — gene or protein identifier

• Accession number — NCBI genome accession (e.g., GCF_00012345.1)

• Taxonomy — phylum, class, order, family, genus level

Use the Advanced Search page for field-specific queries.

Data Sources

HuGGeMs integrates data from multiple sources:

• NCBI RefSeq — reference genomes

• NMDC — National Microbiome Data Collaborative

• PRJDB4176 — colorectal cancer metagenomic cohort

• MetaPhlAn 4 — marker gene database

Genomes are processed through the HuGGeMs pipeline: Kraken/MetaPhlAn classification → dRep dereplication → fastANI clustering → MMseqs2 gene clustering.

HuGGeMs Pipeline

The HuGGeMs update pipeline is available on GitHub. Use it to detect genome presence and update marker genes:

pip install -e .
huggems --help

# Detect genome presence
huggems presence --new-dir ./query/ --input-dir ./ref/ --output-dir ./results/

# Update marker genes
huggems markers --help

Full documentation: GitHub Repository

File Formats

.ffn — FASTA format nucleotide sequences of core genes

.csv — Comma-separated metadata tables

.tsv — Tab-separated annotation files
